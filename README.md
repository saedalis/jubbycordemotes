# Jubbycord Emotes
Renders Uncxity's Emotes in Discord. It uses semicolons instead of colons to not clash with default Discord emotes.

To install:

Install Better Discord.

Copy JubbycordEmotes.plug.js into the Better Discord Plugin Folder.

Enable the JubbycordEmotes plugin.
